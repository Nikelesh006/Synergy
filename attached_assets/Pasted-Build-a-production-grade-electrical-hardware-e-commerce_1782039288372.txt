Build a production-grade electrical hardware e-commerce website named “Synergy”.

Project goal:
Create a modern, professional e-commerce frontend for a general electrical board, switchgear, wiring accessories, tools, safety items, and industrial electrical components store. Use Robu.in as a structural reference only for content density and commerce flow, but do not copy its branding, exact layout, or wording. The result should feel like a real Indian electrical hardware commerce platform for contractors, electricians, builders, maintenance teams, workshops, institutions, and retail buyers. The UI must look deliberate and professionally designed, not like a generic AI-generated landing page.

Design direction:
- Brand name: Synergy
- Industry: Electrical board hardware and electrical supplies e-commerce
- Tone: professional, industrial, trustworthy, clean, commerce-first
- Avoid: emojis, sparkle icons, glowing gradients, purple AI-style visuals, generic “future of” copy, over-rounded cards, floating abstract blobs, and empty decorative sections
- Visual language: structured grid, dense but readable catalog UI, practical product discovery, subtle depth, clean shadows, restrained borders
- Color palette:
  - Primary red for CTA and highlights
  - Secondary blue for navigation, accents, trust sections, and filters
  - White / off-white background for clarity
  - Use neutral grays for text, borders, and surfaces
- Overall look: premium industrial catalog, not startup SaaS, not flashy tech template

Tech stack requirements:
- Next.js
- React
- Tailwind CSS
- Vite-style component cleanliness and fast frontend structure inspiration, but the actual app should be built in Next.js
- MongoDB schema placeholders only
- Do NOT connect the database
- Add models, types, mock data structures, API placeholder files, and comments showing where connection will be added later
- Use TypeScript
- Use App Router
- Use reusable components
- Keep codebase clean and scalable

Important architecture note:
Because Next.js and Vite are separate app systems, use Next.js as the actual framework. Follow a modular frontend structure inspired by modern Vite React organization: clean folders, reusable UI components, isolated mock data, typed utilities, and maintainable architecture.

Core business concept:
Synergy is an electrical hardware and components commerce site that sells:
- MCBs, MCCBs, RCCBs, isolators
- Distribution boards and enclosures
- Switches, sockets, plates, modular accessories
- Wires, cables, cable ties, lugs, glands, conduits
- Contactors, relays, timers, push buttons, indicators
- Fans, lights, drivers, holders, LED accessories
- Power tools and testing instruments
- Industrial electrical consumables
- Safety products such as gloves, tape, helmets, lockout items
- Panels, connectors, terminals, ferrules, busbars
- Motors, starters, panel accessories
- General electrician tools and workshop essentials
